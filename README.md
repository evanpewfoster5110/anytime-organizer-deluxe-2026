A practical way to begin using the application is:

2. Enter tasks, deadlines, notes, and project milestones.
3. Link dependent tasks so their relationships are represented.
4. Inspect the Gantt chart and critical path to assess project timing.
5. Run schedule optimization against the time that is available.
6. Log finished work with the time-tracking tools.
7. Use voice commands for scheduling functions that support them.
8. Turn on offline mode when disconnected, and synchronize again when suitable.

OpenAI and Claude functionality is available after the appropriate API integration has been configured.
